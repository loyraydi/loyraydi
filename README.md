### 🐾 Флагманский проект

## [MeowHUD](https://meowhud.ru) — оверлей нового поколения для трансляций

**Профессиональный игровой оверлей для стримеров и обозревателей турниров.**
Динамическое приближение радара, автоматическое переключение веб-камер игроков по игровым событиям, брендированная кастомизация без перезапуска — всё в реальном времени.

[![Website](https://img.shields.io/badge/🌐_meowhud.ru-visit_website-FF6B9D?style=for-the-badge)](https://meowhud.ru)
![CS2](https://img.shields.io/badge/CS2-поддерживается-000000?style=flat-square)
![Dota 2](https://img.shields.io/badge/Dota_2-поддерживается-A93A31?style=flat-square)
![Valorant](https://img.shields.io/badge/Valorant-в_разработке-FF4655?style=flat-square)

</div>

- 🎯 Динамический зум радара под стандарты профессиональных трансляций
- 📷 Авто-переключение веб-камер игроков без ручной настройки сцен в OBS
- 🎨 Кастомизация стилей и цветовых схем «на лету»
- 📊 Живая статистика: килфид, экономика, таймеры раундов
- 💳 Подписочная модель: бесплатный доступ + Pro-тариф с расширенными стилями
